## 📌 Featured Projects

### 🩺 Agentic Medical Assistance
Agentic RAG system built with **LangGraph + LangChain**, using **Mem0** for long-term memory, **Qdrant** for vector search, and **Tavily** for live web search, backed by a **FastAPI** server (`/chat`, `/history`) with PostgreSQL for conversation state.

### 😷 Real-Time Mask Detection
**YOLOv8**-based two-class (mask / no-mask) real-time inference pipeline optimized for T4 GPU, with automated dataset acquisition via the Roboflow API.

### ⚡ Zapier Email & CRM Automation
AI-powered email triage system using **GROQ** to classify and prioritize Outlook emails, auto-store records in **Airtable**, send scheduled digests, and trigger a Clio-to-Airtable lead-response workflow.
